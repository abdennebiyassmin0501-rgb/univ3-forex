# محاكاة التداول بالشموع اليابانية

منصة تعليمية: كل طالب يدخل باسم مستخدم، يحصل على 500$ افتراضية، ويتداول سهم
**Ford Motor Company (F) — بورصة نيويورك** على بيانات يومية تاريخية حقيقية
(1 جوان → 28 جويلية 2023) من **Yahoo Finance**.

## قواعد المحاكاة
- تظهر في البداية 19 شمعة (اتجاه صاعد بسيط حتى 28 جوان 2023)، ثم 21 مرحلة (شمعة واحدة في كل مرحلة) تتضمن نمطًا واحدًا واضحًا: قمة مزدوجة ثم هبوط.
- الرسم مبسّط: الشموع فقط، مع تكبير/تصغير وعرض الأسعار عند المرور على الشمعة.
- الترتيب: عرض الشموع الظاهرة ← قرار (شراء/بيع/انتظار) ← تنفيذ بسعر **افتتاح الشمعة التالية** ← كشف تلك الشمعة.
- الرصيد والأسعار بالدولار الأمريكي (دون تحويل عملات).
- العمولات وتوزيعات الأرباح مُهملة. الأسعار غير معدّلة بالتوزيعات (كما تظهر في السوق).
- التداول افتراضي بالكامل: لا يوجد أي اتصال بالبورصة، وملف الأسعار للقراءة فقط.

## التشغيل على الحاسوب
```
pip install flask
python app.py
```
ثم افتح http://127.0.0.1:5000

## الاختبارات
```
python -m unittest discover -s tests -t .
```
(اختبار المتصفح يتطلب `playwright`، ويُتخطّى تلقائيًا إن لم تكن مثبتة.)

## الملفات
- `app.py` الصفحات الثلاث · `engine.py` منطق التداول والأرباح · `market.py` بيانات السهم
- `data/F_2023.csv` الأسعار الحقيقية كما نُزِّلت (فبراير–أغسطس 2023؛ تُستعمل منها فترة جوان–جويلية) · `instance/bourse.db` قاعدة البيانات (تُنشأ تلقائيًا)
